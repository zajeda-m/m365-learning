# Microsoft 365 learning

Moje poznámky a praktické ukázky ze studia správy Microsoft 365,
SharePointu Online a Power Automate. Zaměřuji se na automatizaci
a zlepšování firemních procesů.

## Obsah
- `sharepoint/` – struktura webů, knihovny, oprávnění podle rolí
- `power-automate/` – postupy a ukázkové toky
- `entra-id/` – uživatelé, skupiny, přístupy
- `powershell/` – užitečné příkazy
- `microsoft-learn/` – poznámky z kurzů

## Stav
Průběžně se učím. Do repozitáře dávám jen to, co jsem prošel
nebo vyzkoušel.
